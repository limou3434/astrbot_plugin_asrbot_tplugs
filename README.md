# astrbot_plugin_asrbot_tplugs

## 1.前期配置

1. 首先需要准备好一个 `bilibili` 账号
2. 然后在浏览器上登录后，打开浏览器开发者工具（一般是快捷键 `[f12]`），找到 `bilibili.com` 的 `cookie` 数据
3. 按照插件设置中描述需要的字段，把 `cookie` 字段复制过来

## 2.插件作用

梦寝兔兔专用群聊插件：

- **功能 01**：`QQ` 群聊中快速发送留言弹幕到哔哩哔哩直播间，主要针对以下应用场景：① 工作时间无法打开直播间摸鱼（太显眼），利用此方式和主播进行交互，黑听人友好工具；② 账号被封禁，导致无法在直播间中发送弹幕；③ 给群友平时看直播多一些趣味弹幕
    - 使用 `@bot /留言 xxx` 即可快速从 `QQ` 群聊消息转化为弹幕发送到指定直播间，支持添加机器人后私发消息到直播间
- **功能 02**：可以添加群友的生日（支持国历和农历），然后向主播的 `QQ` 账号在群友生日当天进行提醒
    - 使用 `@bot /生日记录 昵称:农历/日历:月份:日期` 即可快速监控群友的生日
    - 使用 `@bot /生日通知 开/光` 即可打开生日通知或关闭生日通知
